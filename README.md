# Real-time Multiplayer Snake Game

A competitive, real-time multiplayer Snake game built with Python Flask and WebSocket technology. Features two-player simultaneous gameplay with collision detection and live score tracking.

## 🚀 Features

- **Real-time multiplayer** - Two players can play simultaneously
- **WebSocket communication** - Instant game state synchronization
- **Competitive gameplay** - Snakes can collide with each other
- **Live scoring** - Real-time score updates for both players
- **Responsive design** - Works across different devices and browsers

## 🛠️ Tech Stack

- **Backend**: Python, Flask, Flask-SocketIO
- **Frontend**: HTML, JavaScript, WebSocket client
- **Async**: Eventlet for concurrent connections
- **Networking**: WebSocket protocol for real-time communication

## 📋 Prerequisites

- Python 3.7+
- pip (Python package manager)
